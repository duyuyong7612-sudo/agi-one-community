# Contributing

Thanks for helping improve AGI-1 Community Controller.

Contributions must stay inside `open-source-edition/` unless a maintainer explicitly
approves a repository-wide change. Do not copy code, prompts, credentials, release
configuration, or assets from the private AGI-1 product tree.

Before opening a pull request:

```bash
npm run verify
```

Public contributions should improve one of these areas:

- Tool schemas and adapters.
- Safety confirmations.
- Step-by-step controller reliability.
- Reproducible benchmark tasks and checkers.
- Documentation that makes boundaries clearer.
- Plugin SDK examples.

Do not add batch action chains, private prompt ports, differential screenshot shortcuts,
voiceprint gates, hard-interrupt logic, memory-enhanced planning, billing code, or private
service URLs to this community tree.
