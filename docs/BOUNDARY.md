# Open / Closed Boundary

This directory is the only prepared public source tree. It is independent from the
private AGI-1 desktop client, private backend, protected prompts, billing service,
release infrastructure, and commercial media.

## Public In This Directory

- Step-by-step community PPAV controller.
- Public one-action tool schemas.
- Basic realtime API connection shape.
- Local file, terminal, and browser adapter interfaces.
- Safety confirmation hooks.
- Plugin SDK.
- Tests, boundary audit, and reproducible benchmark plan.

## Closed Outside This Directory

- Full three-stage realtime voice state machine.
- Voiceprint gating and optimized hard interruption.
- Hybrid realtime voice / three-stage voice / PPAV routing.
- Fast direct execution paths and multi-action batch chains.
- Differential or low-screenshot observation optimization.
- Context compression and memory-enhanced planning.
- Core brain prompts and proprietary prompt routing.
- Complex failure repair and production verification ledger.
- Cloud billing, production credentials, private URLs, release automation, and commercial assets.

## Public Baseline Acknowledgement

The observe-plan-act-observe loop is a common public desktop-agent pattern. This community
edition uses that public pattern because it is inspectable and reproducible. AGI-1's
commercial differentiation is not the existence of a basic loop; it is production voice,
advanced routing, speed, success rate, cost control, and operational hardening.
